# knowledge/ — İş alanı bilgisi

Ajanın "ne" ve "nasıl"ı öğrendiği yer. `rules/` *ne yapılmaz/yapılır* der; `knowledge/` *iş nasıl işler* der.

| Dosya | İçerik |
|---|---|
| `REQUIREMENTS.md` | Gereksinim matrisi, MUST/NICE, varsayımlar |
| `ARCHITECTURE.md` | Bileşenler, güven sınırları, akışlar |
| `DATA_MODEL.md` | Tablolar, kısıtlar, indeksler |
| `THREAT_MODEL.md` | STRIDE, kontroller |
| `OBSERVABILITY.md` | Metrikler, güvenlik olayları, alarm kuralları |
| `ACCEPTANCE.md` | Özellik bazlı kabul kriterleri |
| `contracts/openapi.yaml` | **Entegrasyon sözleşmesi** — REST API (tek kaynak) |
| `contracts/mcp-tools.md` | MCP araç sözleşmesi |
| `domain/glossary.md` | Terimler (TR ↔ EN ↔ kod) |
| `domain/task-lifecycle.md` | Durum makinesi algoritması |
| `domain/rbac-scope.md` | Kapsam ve policy algoritması |
| `domain/dashboard-counting.md` | Dashboard sayım algoritması |
| `domain/recurrence.md` | Tekrarlayan task üretim algoritması |
| `process/orchestration.md` | `/implement-task` sonrası adım adım ne olur |
| `process/ai-observability.md` | history/ ve logs/ formatları, metrikler |
| `tooling/plugins.md` | Kullanılan plugin/skill/MCP'ler ve sağladıkları |
